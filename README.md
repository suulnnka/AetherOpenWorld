# 北京 · Low Poly 开放世界

网页版低多边形(Low Poly)风格的北京开放世界 + 地图编辑器。
纯前端渲染(Three.js),Node/Express 后端负责静态托管与地图存档。

## 快速开始

```bash
npm install
npm start
```

- 游戏: http://localhost:3000/ — 人物在城市中自由行走
- 编辑器: http://localhost:3000/editor.html — 生成/编辑/保存地图

内置两张地图(地图库可切换,游戏默认载入最新保存的一张):
- **北京 · 三环内(OSM 1:4)** — 基于 OpenStreetMap 真实数据重绘(方案见 `docs/osm-plan.md`):
  56 片逐片抓取(Overpass,走 3000 端口中转代理 `/api/osm-proxy`,断点续抓)→ 逐片转换合并。
  实测产出:**34,941 栋 OSM 建筑 → 16,275 个真实轮廓棱柱**(10,362 多边形 + 5,913 聚簇)、
  **9,135 条真实道路**、64 处真实水面(后海/护城河形状)、322 块绿地、17 座风格化地标按真实坐标落位;
  烘焙 18.9MB / 约 10s,浏览器整帧 1.47ms(约 680 FPS 容量)。车流/人群直接跑在真实路网上。
  ```bash
  node tools/osm-import.mjs --all     # 抓取 + 转换(断点续抓,已缓存片自动跳过)
  ```
- **示例 · 北京城(五环)** — 程序化生成的风格化城市(首次启动若无存档自动生成)

## 游戏(开放世界)

| 操作 | 按键 |
|---|---|
| 移动 | `WASD` / 方向键 |
| 疾跑 | `Shift` |
| 跳跃 | `Space` |
| 旋转视角 | 鼠标左键拖拽 |
| 缩放 | 滚轮 |
| 传送地标 | 数字键 `1-9` / `0`(按城市内地标顺序) |

内置功能:第三人称跟随相机、建筑碰撞(可跳上矮台)、小地图、
地标接近名牌(天安门/故宫/天坛…)、**街头生态(不可驾驶,纯观赏)**、
天空/云朵/雾效、实时阴影。

### 街头生态(观赏型 NPC)

环路/长安街上持续有交通与人流,玩家不可驾驶:

- **汽车 7 种**:轿车(6 配色)、出租车(绿白+顶灯)、SUV、面包车、
  公交车(绿白/蓝白涂装)、厢式货车、警车(红蓝警灯)
- **电动车 3 种**:黑骑士、美团黄(黄头盔+外卖箱)、饿了么蓝 — 车道边缘穿行摆动
- **共享单车 4 色**(橙/黄/青/绿):骑手蹬踏动画、车轮同色
- **行人**:10 种上衣 × 5 种裤装配色,迈步摆臂行走动画,沿人行道两侧分布

渲染采用**部件级实例化**:全部 126 个代理(41 车 + 19 电动车 + 16 单车 + 50 行人)
只占 **32 个 draw call**;整车动画(车轮自转/蹬踏/迈步)通过每帧更新实例矩阵实现,
实测整套模拟每帧仅 ~0.2ms。

## 地图编辑器

左侧 8 种工具(快捷键 `Q B G T P W L Y`):

- **选择/移动** — 点击元素选中,拖动移动;`Delete` 删除,属性面板可重掷种子/旋转/缩放
- **街区生成器** — 点击放置一个街区,自动对齐 110m 网格;风格:胡同/老城/现代/CBD
- **大楼生成器** — 单体建筑:宽/深/层数/风格(坡顶平房→玻璃塔)/朝向
- **树木生成器** — 笔刷散布:半径/密度/品种(阔叶/针叶/垂柳/银杏)
- **公园生成器** — 草坪/园路/湖泊/亭子/花境/树木一步生成
- **水域生成器** — 湖泊/河段
- **地标建筑** — 13 种北京地标,半透明预览随鼠标
- **地形生成器** — 整体起伏/远山重新生成 + 隆起/下凹/平整雕刻笔刷

其他:撤销(`Ctrl+Z`)、保存(`Ctrl+S`)、地图库载入/删除、导入/导出 JSON、
「试玩本图」一键跳到游戏(`/?map=<id>`)。

内置地标 **31 座**(编辑器地标工具同步可选):

- 中轴线:奥林匹克塔、冰丝带、鸟巢、水立方、钟楼、鼓楼、雍和宫、景山、故宫、
  妙应寺白塔、天安门、天安门广场、国家大剧院、正阳门、永定门、天坛·祈年殿
- 城东/CBD:央视大楼、中国尊、国贸中心、北京站、望京SOHO、798艺术区
- 城西/西北:中央广播电视塔、北京西站、首钢园(冷却塔+大跳台)、
  颐和园·佛香阁(昆明湖+十七孔桥)、北大·博雅塔(未名湖)、北海白塔
- 城南/西南:北京南站、大兴国际机场、卢沟桥·宛平城

示例城市「示例 · 北京城(五环)」按真实北京格局布置:中轴线南起永定门北至奥塔,
长安街横贯,二环~五环方格路网(350 个街区、约 1400 栋楼、1730 棵树、999 个碰撞体);
CBD 在东、奥园在北、颐和园/未名湖在西北、望京/798 在东北、首钢园在西、
大兴机场在南郊、卢沟桥在西南,远山(西山)环峙。烘焙渲染包约 7MB(服务端 ~1s 烘焙)。

## 架构:后端供数,前端轻渲染

```
                地图 JSON(编辑器保存)                二进制渲染包(~3.5MB)
  编辑器 ──────────────────────────▶ server.js/data ◀── lib/baker.mjs 服务端烘焙
 (创作端,跑生成器)                        │                 ▲
                                          │ /api/maps/:id   │ /api/maps/:id/render
                                          ▼                 ▼
                                     编辑器载入         游戏(city-view.js 瘦渲染器)
```

- **后端负责一切重活**:地图存档管理、示例城生成(启动时自动播种)、
  **服务端烘焙**——在 Node 里把整座城装配为渲染就绪的二进制包
  (顶点 position Float32 + 法线/颜色 Uint8 量化、树实例矩阵、碰撞盒、地形高度场),
  按地图内容哈希做内存缓存 + ETag/304。
- **游戏前端零生成逻辑**:只 fetch 渲染包 → TypedArray 零拷贝视图 → BufferGeometry/InstancedMesh,
  不 import 城市装配器与任何城市生成器;加载从"数秒构建"变为"一次下载"(示例城 3.5MB / 0.5s 烘焙,之后 304 秒回)。
- 运行期压力控制:整城 ~20 个合并 draw call + 树木 InstancedMesh、静态网格 matrixAutoUpdate=false、
  阴影相机跟随角色、**自适应画质**(帧率持续 <40 时自动降低像素比,最低 1.0)。
- **编辑器是唯一的"生成器前端"**(创作工具本就需要实时再生成),保存后服务端烘焙缓存自动失效。

```
server.js                    Express:静态托管 + 地图 API + /render 渲染包端点(缓存+ETag)
lib/baker.mjs                服务端烘焙器:地图 JSON → 二进制渲染包
public/
  index.html                 游戏(渲染端)
  editor.html                编辑器(创作端)
  js/
    rng.js                   种子随机 + 值噪声(全部生成器确定性可复现)
    palette.js               全局配色
    mesh-builder.js          图元合并器(盒/柱/锥/回转体→单顶点色 BufferGeometry)
    collider-grid.js         碰撞空间哈希(游戏端/装配器共用)
    city.js                  城市装配器(服务端烘焙与编辑器共用)
    landmarks.js             13 个北京地标(低模拼装)
    demo-city.js             示例北京城生成(布局/街区/公园/地标/行道树)
    generators/
      terrain.js             高度场地形:噪声起伏+远山+城市压平+雕刻笔刷
      building.js            大楼生成器(5 种风格)
      block.js               街区生成器(胡同院落/板楼/塔楼/CBD 布局)
      park.js                公园生成器
      tree.js                树木实例化(4 品种 + 烘焙数组直接构建实例网格)
    game/
      city-view.js           瘦渲染器:渲染包 → 场景(零生成逻辑)
      character.js           角色控制/相机/碰撞
      agents.js              街头生态:汽车/电动车/单车/行人(部件级实例化)
      main.js                主入口 + 自适应画质
    editor/editor.js         编辑器全部工具与交互
data/maps/*.json             服务器地图存档
test-smoke.mjs               冒烟测试(装配/增量/烘焙回环,node test-smoke.mjs)
```

渲染包格式:`[u32 manifest 长度][manifest JSON][二进制块]`,块内偏移 4 字节对齐;
manifest 描述 chunks(含地形网格)、树木实例、碰撞盒、高度场、地标/水域/公园矩形等。
